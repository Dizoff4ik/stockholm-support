# Stockholm Support — визуальный прототип

Откройте `index.html` в браузере.

## Уже реализовано
- Изумрудная стилистика Jade Palace.
- Боковое меню скрыто при загрузке; появляется по нажатию на кнопку из трёх полосок и закрывается по крестику, фону или выбору раздела.
- 14 разделов с навигацией.
- Адаптация под мобильные экраны.
- Демонстрационные карточки, таблицы, колесо, шар предсказаний и зайчик-помощник.
- Макет входа и регистрации.

## Важно
Это frontend-прототип. Реальная регистрация, авторизация, Discord OAuth2, PostgreSQL, роли, права доступа и сохранение данных ещё не подключены. Не используйте демонстрационную форму для настоящих паролей.
